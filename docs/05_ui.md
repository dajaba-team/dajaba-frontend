# 05. UI·스타일·접근성

> v0.1 · 2026-10-31 · 초안(팀 확인 중) · 정리 지윤

[참고 화면](https://count-equal-46959360.figma.site/)의 짙은 탐색 영역, 상단 헤더, 밝은 배경과 표 카드를 기준으로 해요. 참고 화면에만 있고 API가 없는 메뉴·가상 통계는 실제 화면에 넣지 않아요(시연 `/demo`에만).

## 1. 파일 역할 [FE 코드]

| 파일                               | 역할                                                                                          |
| ---------------------------------- | --------------------------------------------------------------------------------------------- |
| `src/shared/styles/tokens.css`     | 색상·간격·폰트·radius·shadow 토큰 (CSS 변수)                                                  |
| `src/shared/styles/GlobalStyle.js` | 기본 요소, 키보드 포커스, 모션 설정 (styled-components 전역 스타일)                           |
| `src/app/styles/app.css`           | 앱 공통 탐색·레이아웃                                                                         |
| `src/features/{기능}/styles/*.css` | 그 기능 전용 CSS (예: `cases.css`)                                                            |
| `src/shared/ui/`                   | 공통 컴포넌트 — `AsyncState`(로딩·빈 결과·오류·재시도), `dashboard/`의 버튼·배지·모달·빈 상태 |

## 2. CSS 규칙

- 색·간격·글꼴은 **토큰만** 써요(`var(--…)`). 새 값이 필요하면 `tokens.css`에 먼저 추가.
- 클래스는 kebab-case, 상태는 `is-active`·`is-disabled`처럼 `is-` 접두어.
- 중첩 없이, 인라인 `style`·`!important` 없이.
- 전역 기본 스타일은 `GlobalStyle.js`(styled-components), 레이아웃·기능 스타일은 CSS 파일. 같은 요소에 둘을 섞지 않아요.
- 상태 값(`PENDING_APPROVAL` 등)은 색만으로 구분하지 않고 **글자를 같이** 보여 줘요.

## 3. 반응형

- 기본은 모바일 세로 배치. `min-width: 48rem`부터 Grid `15rem minmax(0, 1fr)`로 사이드바·본문 분리.
- 간격은 Flexbox `gap`, 본문 여백은 rem 토큰, 제목 크기는 `clamp()`.
- 표는 최소 너비를 지키고 **표 영역에서만** 가로 스크롤(페이지 전체가 밀리지 않게).

## 4. 접근성 [FE 코드, 예전 「UI 구현 예시」]

| 항목        | 규칙                                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------------------ |
| 건너뛰기    | 첫 요소에 "본문으로 건너뛰기" → `#main-content`                                                        |
| 폼          | 모든 입력·select에 보이는 `label`                                                                      |
| 표          | `caption`(숨김 가능) + 열 제목 `scope="col"`                                                           |
| 메뉴        | 현재 메뉴에 `aria-current="page"`                                                                      |
| 변화 알림   | 페이지 이동·저장 결과는 `aria-live="polite"` / `role="status"`                                         |
| 스크롤 영역 | `role="region"` + `aria-label` + `tabIndex=0` (키보드로 스크롤)                                        |
| 포커스      | `focus-visible` 윤곽선을 지우지 않음                                                                   |
| 크기        | 버튼·select 최소 높이 2.75rem                                                                          |
| 대비        | 본문 `#182438`, 보조 `#526176`, 링크 `#294eb5` — 흰 배경에서 WCAG AA 4.5:1 이상. 색을 바꾸면 다시 확인 |
| 모션        | `prefers-reduced-motion`이면 애니메이션·전환·부드러운 스크롤 끔                                        |
| 확인        | 종결·반려·승인처럼 되돌릴 수 없는 버튼은 확인 단계 + 사유 입력                                         |

## 5. 화면 상태 네 가지

조회 화면은 항상 **로딩 · 빈 결과 · 오류(+다시 시도) · 정상** 넷을 그려요. `AsyncState`를 써요.
상세 안의 독립 영역(근거 거래·현재 초안·AI 요약)은 **각자 실패**해요 — 요약이 실패해도 거래 열람·배정·메모는 돼요. 케이스 자체 조회가 실패할 때만 상세 전체를 오류로.

## 6. HTML 예시 — 케이스 목록

React가 그리는 핵심 구조의 정적 예시예요. 실제 필터·페이지 이동은 JSX 이벤트와 URL 상태에 연결돼 있어요. 같은 모양을 내려면 `tokens.css` → `app.css` → `cases.css` 순으로 불러와요.

```html
<a class="skip-link" href="#main-content">본문으로 건너뛰기</a>
<div class="app-shell">
	<aside class="app-sidebar" aria-label="업무 공간">
		<a class="app-brand" href="/cases">DAJABA<span>AML 인텔리전스</span></a>
		<nav class="app-navigation" aria-label="주요 메뉴">
			<a class="navigation-link is-active" href="/cases" aria-current="page">조사 케이스</a>
		</nav>
	</aside>
	<div class="app-workspace">
		<header class="app-header">
			<span>AML OPERATIONS</span><span>조사 · 검토 · 보고</span>
		</header>
		<main id="main-content" class="app-main" tabindex="-1">
			<header class="case-page-heading">
				<h1>케이스 목록</h1>
				<p>의심 거래의 근거를 확인하고 조사 내용을 기록하세요.</p>
			</header>
			<section class="case-panel" aria-label="케이스 조회">
				<label class="case-filter"
					>상태 필터
					<select>
						<option>전체</option>
						<option>REVIEWING</option>
					</select>
				</label>
				<div
					class="case-table-scroll"
					role="region"
					aria-label="케이스 목록 표"
					tabindex="0"
				>
					<table class="case-table">
						<caption class="visually-hidden">
							상태 필터에 해당하는 케이스와 담당자
						</caption>
						<thead>
							<tr>
								<th scope="col">케이스</th>
								<th scope="col">상태</th>
								<th scope="col">담당자</th>
							</tr>
						</thead>
						<tbody>
							<tr>
								<td><a href="/cases/1001">반복 고액 이체 조사</a></td>
								<td><span class="case-status">REVIEWING</span></td>
								<td>예시 조사원</td>
							</tr>
						</tbody>
					</table>
				</div>
				<nav class="case-pagination" aria-label="페이지">
					<button disabled>이전</button><span aria-live="polite">1 페이지</span
					><button>다음</button>
				</nav>
			</section>
		</main>
	</div>
</div>
```
